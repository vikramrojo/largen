# composition-that-verifies

Teach the contract to compose, then make each thing it teaches able to fail

Two waves. Wave 1 shipped as 0.4.0: the `--space-*` scale, the `pad-in-rem`
warning, and a `composition` section in the contract. Wave 2 acts on what happened
when that shipped contract met a real brief — of five composition topics, only the
one with a verifier behind it changed the output.

Renamed from `spacing-and-composition`, which stopped describing the change once
the finding was that guidance without enforcement is decoration.
