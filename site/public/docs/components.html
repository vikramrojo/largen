Reference components

Optional, and copy-in rather than imported. largen ships an algebra, not a dependency — take the source and it is yours to edit.

Every one of these is six or so lines, because the tones, the variants, the sizes and both themes come from the layers underneath. Fetch any of them over MCP with get_component_source, or read reference.css directly.

Feedback

alertA message reporting a state. Use with a tone.
badgeA short inline label or count.
dotA bare status dot. No content.
spinnerAn indeterminate activity indicator.
skeletonA loading placeholder occupying a future element's box.

Surfaces

cardA container grouping related content on a surface.
panelA surface with no border.
dividerA labelled or bare horizontal rule.

Data

statA figure with a label. Wraps stat-label and stat-value.
stat-labelThe label above a figure.
stat-valueThe figure itself. Renders tabular-nums.

Navigation

menuA vertical list of navigation or action items.
crumbsAn ancestry trail.
stepsA numbered sequence. Mark position with aria-current.

Conversation

bubbleA conversation bubble. data-side="end" for the user's own turn.
avatarA person's image or initials.

Overlay

tipWraps a child; hint text goes in data-tip.

Text

proseLong-form rendered text. Wrap markdown output in this.

Layout utilities

stackVertical layout. Set --gap.
rowHorizontal layout, no wrap.
clusterHorizontal layout that wraps. Tag lists, icon groups.
gridAs many columns as fit at --min-item.
centerConstrained measure, centred.

Using them

<link rel="stylesheet" href="https://largen.dev/largen.css">
  <link rel="stylesheet" href="https://largen.dev/largen.components.css">

Or copy one component's source and skip the file. That is the intended path — the reference set exists to be read and taken from, not depended on.
